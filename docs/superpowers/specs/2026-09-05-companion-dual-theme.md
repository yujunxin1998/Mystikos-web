# 陪玩模块双主题视觉完善规格

## 目标

参考用户提供的陪玩清单页与详情页设计图，继续完善当前已经实现的“深夜会所”布局，并修复浅色主题下深浅色块、文字、控件和媒体遮罩不协调的问题。

## 范围

- 陪玩清单页 `/companions`：Hero、搜索与筛选、今晚推荐、全部陪玩卡片、空状态、分页。
- 陪玩详情页 `/companions/[slug]`：身份档案、相册、预约面板、语音与视频内容、状态与反馈。
- 桌面、平板与手机断点。
- 深色和浅色主题。

## 设计约束

- 深色主题延续参考图中的午夜蓝紫背景、柔和紫色描边与香槟金强调色。
- 浅色主题采用月白页面、淡紫卡面和克制的香槟金；Hero 与媒体图片允许保留夜景氛围，但媒体外的信息面板必须完整切换为浅色。
- 媒体上的文字、收藏按钮和状态徽标统一使用独立的 on-media 配色，不受页面主题反转影响。
- 表单、筛选器、分页、空状态、语音和视频卡片必须具有明确的浅色状态与键盘焦点。
- 保留搜索、筛选、收藏、分页、画廊、登录跳转与预约接口行为，不修改数据模型和 API。
- 详情页不再嵌套第二个 `main` landmark。

## 验收

- 主题切换后，清单与详情页不出现浅色卡面上的白字、深色表单残留或不可辨识边框。
- Dark/Light 主题中的交互控件均具有 hover、active、focus-visible 和 disabled 状态。
- 960px、800px、720px 以下布局不横向溢出，触屏设备不依赖 hover 才能看到必要操作。
- 现有测试、类型检查和构建通过。
